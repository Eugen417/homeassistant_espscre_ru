    Hoe werkt het dagelijks?

    Zoek een entiteit, voeg deze toe en klik op Opslaan & naar scherm. De app houdt de status bij. Voor een kleurenlamp: houd de tegel ingedrukt voor kleur, temperatuur en helderheid. Climate, vacuum en cover openen hun kaart direct. Sensoren tonen alleen hun waarde.

    Alleen nieuwe firmware vraagt om een installatie via ESPHome Device Builder. Je tegels blijven in deze app bewaard. Een offline scherm krijgt de wijzigingen zodra het terug is.

    NIEUW SCHERM

    Van USB naar aan de muur.

    Kies je scherm. Elk bestand krijgt eigen sleutels voor een veilige koppeling en draadloze updates.

    Welk scherm heb je?

    1. Open ESPHome Device Builder. Voeg een nieuw apparaat toe, sla de eerste installatie over en vervang de inhoud via Edit door het gedownloade bestand.
    2. Vul wifi eenmalig in bij Secrets. Gebruik wifi_ssid en wifi_password.
    3. Sluit USB aan op je Home Assistant Raspberry. Klik Install → Plug into the computer running ESPHome Device Builder en kies de USB-poort.
    4. Koppel in Instellingen → Apparaten & diensten → ESPHome. Gebruik de api.encryption.key uit je bestand en sta Home Assistant-acties toe bij Configureren.
    5. Open deze pagina en kies je tegels. CYD toont bij de eerste start een kalibratie: tik ieder kruisje drie keer. Guition hoeft niet gekalibreerd.

    Bewaar je YAML met sleutels. Gebruik later Install → Wirelessly voor firmware-updates. Tegels wijzigen doe je hier.
